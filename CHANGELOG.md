## [0.1.0] — 2026-11-07

Первый выпуск.

### Добавлено

- Файлы-приманки в каждой защищённой папке: создание, проверка раз в минуту, починка после инцидента.
- Наблюдение через ETW (`Microsoft-Windows-Kernel-File`, `Microsoft-Windows-Kernel-Process`)
  с определением процесса-виновника; ограниченный режим без прав администратора.
- Баллы подозрительности: приманки, всплески активности, энтропия, испорченные сигнатуры форматов,
  подозрительные переименования, записки о выкупе, удаление теневых копий.
- Заморозка процесса, решение пользователя «Убить / Разрешить», автоматическое завершение по таймеру.
- Резервные копии изменившихся файлов с несколькими версиями; восстановление после инцидента
  и карантин для зашифрованных файлов.
- Белый список процессов (по имени или полному пути) и исключения папок.
- Режим обучения.
- Главное окно с разделами «Обзор», «Журнал событий», «Защищённые папки», «Белый список»,
  «Резервные копии», «Настройки»; окно критической тревоги поверх всех окон.
- Значок в трее с меню, уведомления Windows с кнопками, автозапуск через Планировщик заданий.
- Журнал событий и инцидентов в SQLite.
- Безопасный симулятор атаки `ransim` для проверки.
