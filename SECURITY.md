# Безопасность

Folder Guard — программа защиты, поэтому уязвимости в ней особенно важны.

## Поддерживаемые версии

Исправления выходят только для последней версии.

| Версия | Поддерживается |
|---|---|
| 0.1.x | ✅ |

## Как сообщить об уязвимости

**Не создавайте публичный issue.** Опубликованный способ обойти защиту — подсказка авторам вредоносных программ.

Сообщите приватно через вкладку **Security → Report a vulnerability** этого репозитория
(GitHub Private Vulnerability Reporting).

Пожалуйста, укажите:
- версию Folder Guard и Windows;
- что именно можно сделать (обойти обнаружение, остановить защиту, повредить резервные копии и т. п.);
- шаги или код для воспроизведения. Для проверки используйте `ransim` или собственную песочницу,
  а не настоящий вредоносный код.

Ответ — в течение 7 дней. После исправления уязвимость будет описана в CHANGELOG с благодарностью автору
(если вы не против).

## Что считается уязвимостью

- обход обнаружения, который не требует прав администратора;
- возможность обычного процесса остановить защиту или изменить её настройки;
- порча или подмена резервных копий и карантина;
- выполнение кода через файлы, которые читает программа (журнал, настройки, копии).

## Что известно и уязвимостью не считается

Эти ограничения описаны в README:
- реакция происходит после записи, поэтому несколько файлов успевают пострадать;
- процесс с правами администратора может завершить Folder Guard;
- запись через отображение в память не видна ETW как запись (для приманок есть подстраховка).
